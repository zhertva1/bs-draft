👑 ВЫБОР КАРТЫ (ТОЛЬКО ДЛЯ АДМИНА)

📋 ИНСТРУКЦИЯ ДЛЯ АДМИНИСТРАТОРА

  • 1. Выберите режим игры (вкладка выше)
  • 2. Выберите конкретную карту из списка
  • 3. Нажмите "ВЫБРАТЬ КАРТУ" - карта появится у всех участников
  • 4. Когда команды будут готовы, они нажмут "ГОТОВ" на своих страницах
  • 5. Драфт начнется автоматически
  • 6. Используйте "СБРОСИТЬ ДРАФТ" для начала нового матча

🎮 ИНСТРУКЦИЯ ДЛЯ ИГРОКА

  • 1. Нажмите кнопку "ГОТОВ" выше, когда будете готовы к драфту
  • 2. Дождитесь, когда вторая команда также нажмет "ГОТОВ"
  • 3. Следуйте указаниям в верхней панели (когда ваша очередь банить или выбирать)
  • 4. Выбирайте бравлеров кликом по карточкам выше
  • 5. Активный слот подсвечивается зеленой анимацией
