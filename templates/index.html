ИЗМЕНЕНИЕ НАЗВАНИЙ КОМАНД

ИНСТРУКЦИЯ ДЛЯ АДМИНИСТРАТОРА

  • Выберите режим игры (вкладка выше)
  • Выберите конкретную карту из списка
  • Нажмите "ВЫБРАТЬ КАРТУ" - карта появится у всех участников
  • Когда команды будут готовы, они нажмут "ГОТОВ" на своих страницах
  • Обе команды должны нажать "ГОТОВ" для начала драфта
  • Драфт начнется автоматически: 40 секунд на все баны
  • Во время банов команды могут банить одинаковых бойцов
  • После банов: 40 секунд на каждый пик по очереди
  • Во время пиков нельзя выбирать одинаковых бойцов
  • Не успели? Система выберет случайного бравлера!
  • Для пикнутого бравлера можно выбрать гаджет (клик по иконке справа внизу)
  • Используйте "НОВЫЙ ДРАФТ" для начала нового матча (карта сохраняется)
  • Используйте "СБРОСИТЬ ДРАФТ" для полного сброса (включая карту)
  • Используйте форму выше для изменения названий команд
